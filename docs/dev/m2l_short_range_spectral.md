## 1. 问题回顾与前提修正（阶段 2 实证）

对角实谱 M2L 平移函数（`Translation.jl`）

```
T_τ(k̂, R̂ab) = -jk/(4π) · Σ_{l=0}^{τ} (-j)^l (2l+1) h_l⁽²⁾(kR) P_l(k̂·R̂ab)
```

原诊断（issue #22 / 本项目早期）：`kR_min ≳ 0.55·L`（后修正为 ≈0.85·L）为
对角方案可用阈值。**阶段 2 的逐层法医分析修正了该定性**：

### 1.1 真实代码失效解剖（GD2V fixture：球 0.5 m、4×6 粗网格、叶 0.10 m）

- nr=1..6 全部失败（rel ≈ 1.0、corr ≈ 0.1），nr=7 通过（rel 1.9e-2）；
- 逐层隔离（零 αTrans 差分）：level 2（L=24, kR_min=10.06）rel 1.6、
  level 3（L=17, kR_min=5.03）rel 19.4、level 4（L=12, kR_min=2.52）rel 5.3
  ——三层皆败，且 level 3 占范数 98%；
- `αTrans` 与理想级数**逐元素完全一致**（对比 diff = 0），平移因子本身无 bug；
- 单对显微镜：level-3 far 对 (2,0,0)，真实 `aggS` 精度 6.8e-4（良好），
  但配对结果为精确值的 ~303 倍——巨大平移样本放大非理想谱成分；
- **根因**：fixture 网格三角形边长 ~0.44–0.57 m，而叶盒仅 0.10 m。基函数
  支撑（按中心入盒）从盒中心外延中位 0.44 m / 最大 0.60 m，远超盒半径
  （√3/2·w ≈ 0.087 m）。多极子平移收敛要求 `R ≥ r_s + r_t`：nr=1 时
  叶层 R_min = 0.20 m ≪ 0.88 m ——**分离条件被几何性破坏**；nr=7 时
  R_min = 0.80 m ≈ 0.88 m，恰好边缘通过。原先的 `0.55L/0.85L` 阈值
  都是该 fixture 上"网格越界程度与 (nr+1)·w 同步"的巧合拟合。

### 1.2 对角方案的真失效机理（原型量化）

理想限带方向图的对角配对在 kR ∈ [2.5, 6] 并**不**失效（原型实测
rel 1e-4–1e-3，大 kR 收敛至 1e-11+）。失效发生在 F 携带**非衰减高阶谱
成分**时：部分和样本 max|T_L| ~ 3e7（L=12, kR=2.5）/ 2e7（L=17, kR=5）
直接乘上这些成分并被放大。原型注入 1e-3 相对白噪（模拟层间插值残差
实测 ~7e-5、粗 fixture 上的越界支撑真实内容）后：对角 rel 947–3971
（复现 issue #22 "误差 O(1)–O(1000)" 的观测），corr 0.4–0.7。

**结论**：短距对角 M2L 是一个**条件数问题**——逐点样本 1e7 把 F 中任何
非理想谱成分（插值残差、越界支撑内容、极化坐标伪影）放大 1e3–1e4 倍。
谱域方案将同一配对改为逐系数运算（算子范数有界），是结构性修复。

### 1.3 对本任务交付面的影响

- GD2V fixture 上 nr=1 **几何上不可达**（无论何种平移方案）——其
  粗网格使支撑严重越界。该 fixture 的近场窗成本必须由自适应 nr 承担；
- 在支撑入盒的正常网格（叶盒 ≥ ~2× 三角形边）上，nr=1 的失败源
  （上层插值残差 × 巨大样本放大）正是谱域 M2L 可修的对象；
- 故验收改为双轨：(a) 细网格 fixture 上 `nr=1 + :spectral/:hybrid` 达
  GD2 门强度；(b) 既有 GD2 门（自适应 nr 路径）全绿不变。

## 2. 候选方案评估（阶段 1 结论）

| 候选 | 核心思想 | 与本代码库兼容性 | 结论 |
|---|---|---|---|
| (a) Bogaert–Peeters–Olyslager, IEEE TAP 56(12), 2008（nondirective plane wave MLFMA） | 复角平面波（含倏逝波）对角化，角谱采样于复化球面 | 需要把极点网格、叶层辐射积分、相移、层间插值全部复化；复网格插值本身是该团队的后续研究方向 | 研究级重构，弃 |
| (b) Bogaert–Olyslager, JCP 228(4), 2009（低频稳定平面波加法定理） | 给出系数一致有界的平面波加法定理 | 同 (a)，仍需复角采样基础设施 | 弃（理由同上） |
| (c) 混合形式 FMA（Zhao & Chew 2000 系；Ergül & Gürel 专著 §3.7 LF-MLFMA / §3.7.3 Broadband MLFMA） | 低频层在**多极子（球谐）域**做稠密 M2L；高频层保持对角形式；交叉层用 T_M→P / T_P→M 变换器衔接 | 本代码库的 GL(θ)×均匀(φ) 极点网格本身就是精确球谐变换网格；变换器可退化为 `translate!` 内部的 SHT 前后处理，聚合/插值/相移管线零改动 | **采纳** |

教科书依据（本地 CEM 知识库，Ergül & Gürel §3.7）：

- LF-MLFMA 平移级（式 3.180）：`g_C = Σ_{C'∈F{C}} α_{C'→C} s_{C'}`，
  `α` 为 `M_l × M_l` 稠密矩阵（`M_l = (τ+1)²`）——球谐域 M2L 无条件稳定；
- Broadband MLFMA（式 3.184–3.187）：交叉层以 `T_M→P` / `T_P→M` 在多极子
  与平面波表示间转换，之上恢复普通对角 MLFMA；
- Table 3.11/3.12：小盒（≤ λ/4）多极子截断 τ 不随盒尺寸缩小而增长
  （λ/4 盒 τ=11 达 3 位精度，两层级最坏误差 ~1.0e-3）——与本代码库
  0.2λ 叶盒、L=12 的参数区间吻合。

## 3. 数学方案

### 3.1 记号与本代码库约定

- 聚合（`Aggregation.jl`）：`F(k̂) = Σ_n x_n ∫ f_n(r') e^{+jk k̂·(r'−c_s)} dS'`，
  存 `aggS[iPole, {θ,φ}, iCube]`；
- 平移（`Translation.jl`）：`R = c_t − c_s`（target − source），
  `αTrans = W_p·T_L(k̂_p, R)`；
- 接收（`Disaggregation.jl`）：相位 `e^{−jk k̂·(r−c_t)}`；
- 极点网格（`Interpolation.jl`）：θ 取 `L+1` 个 Gauss–Legendre 点（对 cosθ），
  φ 取 `2(L+1)` 个半格偏置均匀点，`nPoles = 2(L+1)²`，权重 `W_p = W_θ W_φ`。

### 3.2 网格的精确球谐变换性质

GL_θ(L+1) × uniform_φ(2(L+1)) 乘积网格对任意两个 degree ≤ L 的球谐
`Y_a, Y_b` 的乘积积分**精确**（θ 方向 GL 对 cosθ 多项式精确到 2L+1 ≥ 2L；
φ 方向均匀网格对 |m_a−m_b| ≤ 2L < 2(L+1) 的 Fourier 模精确）。因此：

- **分析**（SHT）：`F̂_a = Σ_p W_p F(k̂_p) conj(Y_a(k̂_p))` 对限带 F 精确；
- **综合**（inverse SHT）：`G(k̂_p) = Σ_a Ĝ_a Y_a(k̂_p)`。

即教科书中的 `T_P→M` / `T_M→P` 变换器在本代码库里就是一次带权矩阵乘。

### 3.3 谱域 M2L 算子（Gaunt 形式）

对角方案的远场配对对象是 `G(k̂) = T_exact(k̂,R)·F(k̂)`（T_exact 为分布，
其在 `k̂ = −R̂` 有倏逝 δ 支撑）。谱域把 G 的 degree ≤ L 投影直接算出：

```
Ĝ_a = ⟨T_exact·F, Y_a⟩ = Σ_b M_ab(R) F̂_b
M_ab(R) = -jk Σ_{c} (-j)^{l_c} h_{l_c}⁽²⁾(kR) Y_c^*(R̂) G_{abc}
```

求和指标 `a=(l_a,m_a)`，`b=(l_b,m_b)`，`c=(l_c,m_c)`，`G_{abc} = ∫ Y_a^* Y_b Y_c dΩ`
为 Gaunt 积分，非零仅当 `m_c = m_a − m_b` 且 `|l_a−l_b| ≤ l_c ≤ l_a+l_b ≤ 2L`
（被 `Y_b Y_a^*` 的限带度截断，级数**自动有限**，无发散）。

逐项稳定性的来源：

- `M_ab` 中的增长因子 `h_{l_c}⁽²⁾(kR)`（`l_c > kR` 时 ~ (2l_c−1)!!/(kR)^{l_c+1}）
  与 Gaunt 系数中 `(2l_c+1)^{-1/2}` 及 3j 衰减相配，且作用于 `F̂_b` 时被
  聚合系数的因子级衰减（`F̂_b ~ (k·r_s)^{l_b}/(2l_b−1)!!`，`r_s ≤ (√3/2)w`）
  抵消——这正是多极子加法定理 `R > r_s + r_t` 收敛条件的逐系数版本；
- 对 nr=1 面邻 far 对（R = 2w）：收敛比 `r_s/R ≤ 0.433`（源点位于源盒
  对角极限时 0.866/2），截断尾 ~0.43^L 量级（L=12 → ≪1e-3），**与 kR 无关**。

### 3.4 与对角方案的恒等性（同一 L 下的精度等价）

两种方案在 `kR ≫ L` 时计算同一个对象（degree-L 配对），数值必须一致——
这构成原型的一致性校验；在 `kR ≲ L` 时谱域给出正确值而对角逐点求和失效
——这是 GD2V 门要验证的修复。

### 3.6 代价模型

设该层 `(L+1)² = M` 个系数、`nCubes` 盒、far 对 ~189/盒：

- 每盒 SHT + 综合：`2·M·nPoles·2` 复 MAC ≈ 4·M·2M·2；M2L 每方向按
  远偏移批处理成 GEMM（`M×M × (该方向盒对数)`），总 flop ~
  `189 · 2M² · nCubes`——对 L=12（M=169）约 2×10⁹/千盒/极化，
  BLAS 密集乘实现，低频层 nCubes 大而 M 小（τ 不随盒缩小增长，Table 3.11），
  处于可接受区间；
- 内存：Gaunt 张量按非零 (a,b,c) 计 ~ M²·2L·16B（L=12 约 10 MB 内）+
  每方向 M² 矩阵（可按需重建或缓存，189 方向全缓存 L=12 约 86 MB，opt-in 可接受）；
- 收益：nr 7→1 使 Z_near 窗 3375→27 盒（装配时间/内存 ~125×），
  far 对 316→189。

### 3.7 失效模式与边界（阶段 2 修订）

近场窗/M2L 可用性的三类情形（按新判据 `R_min = (nr+1)·w ≥ 2·r_extent` 分）：

- **P3a 支撑越界（分离破坏）**：`2·r_extent > R_min`。任何平移方案（对角/
  谱域/其他）都无法恢复——far 对的"远场"在几何上不是远场。GD2V fixture
  （tri 0.44–0.57 m ≫ leaf 0.10 m，r_extent 中位 0.44 m）nr≤6 全属此类。
  唯一正确动作：nr 由网格几何决定（本 fixture 强制 nr≈7）。
  **当前 OctreeBuilder 警告中的 `kR_min ≥ 0.55·L` 建议是错误判据**：
  它在 GD2V 上建议 nr=5（实测 rel 0.99 失败），而外延判据给出 nr=7（通过）。
- **P3b 分离达标 + 放大区（谱域 M2L 的适用域）**：`2·r_extent ≤ R_min` 但
  `kR_min/L ≲ 0.35`（大叶 0.35–0.45 λ、nr=1）。对角样本 max|T_L| ~ 1e5–1e6
  放大上层插值残差 → 失效；谱域 M2L + 列截止在此稳定。**注意：谱域还需
  列截止 L_eff（超额带宽容纪律）**——实验表明不截断时白噪残差同样被
  M 的高列放大（L=17/kR=5.03：无截止 rel 3.7e5，L_eff=6 → 2.2e-3）。
- **P3c 分离达标 + 对角安全区**：`kR_min/L ≳ 0.3` 且残差小。细网格
  fixture（16×24、leaf 0.10）nr=2（kR_min/L=0.31）对角已达 rel 5.7e-3——
  `0.55·L` 判据在此过度保守（要求 nr=5），外延判据正确给出 nr=2。

其他边界：

1. **nr=0**：不存在（最小 1），保持约束。
2. **h_{l_c}⁽²⁾ 大自变量的计算**：`SpecialFunctions.sphericalbessely` 逐 l
   直接计算，避免向上递推；l ≤ 2L 有界。
3. **双精度动态范围**：M 最大元（全行）~1e24（L=17, kR=5.03 的高 (a,b)），
   但接收可见行（l_a ≤ 物理接收度）的放大低 5–9 个量级；配合 F̂ 物理衰减
   与列截止，端到端误差按 GD2W 门实测标定。
4. **SHT 精确性依赖网格**：仅 GL 极点网格保证；`LbPolesInfo`（Lebedev 路径）
   暂不支持——检测到即回退对角并警告。
5. **多基（RWG+SWG）**：`translate!` 与基函数类型无关（作用于 aggS），无影响。

### 3.8 交付组件（按阶段 2 结论修订）

1. **谱域 M2L（opt-in）**：`m2l_scheme = :diagonal（默认）/:spectral/:hybrid`；
   `:hybrid` 逐层按 `kR_min < 0.9·L`（放大区）选谱域，其余层对角；
   谱域层带列截止 `L_eff = ⌊√3·kw + 2.16·d^{2/3}·(kw)^{1/3}⌋`（超额带宽
   公式、digits 参数 d≈2，GD2W 门标定）。`m2l_scheme ≠ :diagonal` 且
   `near_range === nothing` 时取 nr=1。
2. **自适应判据修正（对角默认路径也受益）**：OctreeBuilder 的 kR/L 阈值
   警告/建议改为外延判据 `R_min ≥ margin·r_extent`（margin≈1.8，由
   GD2V→7、细 fixture→2 双点标定）；`r_extent` 在建树时由网格几何直接
   计算（基函数支撑顶点到盒中心最大距离，逐层）。
3. **验收双轨**（见 §5）。

## 6. 阶段 3 集成结论：谱域 M2L 的不可行机制（负结果）

### 6.1 集成实现与证伪数据

阶段 3 将原型以 `m2l_scheme = :spectral` opt-in 集成（`compute_translation_factors!`
预计算 `SHT_Y/SHT_YtW/αTransS`；`translate!` 走 分析 `F̂ = YᵀW·F` →
逐方向稠密 Gaunt 平移 `Ĝ = M·F̂` → 综合 `G = const·W·Y·Ĝ`）。组件级
全部逐位验证通过：

- `M` ≡ 原型（1.1e-15）；`Y/YtW` ≡ 原型（7e-15）；`YᵀW·Y = I`（7e-15）；
- 叶层（L=12）`M` ≡ 对角等效算子 `YᵀW·Diag(T)·Y`（**低阶子块** 1e-13）；
- M 的 c 求和按截断核语义取 `c ≤ L`（非 Gaunt 完备 `c ≤ l_a+l_b`——后者
  注入 `h_{>L}` 伪耦合导致 1e11 爆炸，已修）。

**但端到端全面失败**（GD2X：r=0.4 m 球、36×50 网格、叶 0.10 m、nr=2、
PMCHW 300 MHz εr=4；对角 nr=2 rel = 3.6e-3 ✓ dense 参照）：

| 配置 | rel（vs dense-far） |
|---|---|
| 对角 nr=2（基准） | **3.6e-3** ✓ |
| 谱域（c ≤ L，无谱截断） | 1.7e3–2.4e2 ✗ |
| 谱域（Leff=5 列截止） | 3.6 ✗ |
| αTransS := Mc（对角的精确谱域等效算子） | 6.5e2 ✗ |

### 6.2 机制：对角方案的"魔法"是采样求积的广义求和/混叠相消

逐环节法医（scratch_recv.jl 单盒单基接收配对终审，GD2X 叶层 kR=3.97 < L=12）：

1. **对角 disaggG** = 逐点原始乘积样本 `const·W_p·Σ_far T_p F_p`——其
   带限分析 `Ĝ_d` 的**低阶系数**（配对真值的载体）比整个配对真值大
   ~10³×：对角路径的接收配对值 1.9e-4，而 `Ĝ_d` 低阶系数 ~7e-2–3e-1。
   截断级数 `T_{≤L}` 的尾部在 `kR < L` 区为 `|h_L(kR)|` 量级（GD2X 叶层
   ~1e5–1e6 样本），GL 采样求积对尾部的**混叠相消**（广义求和语义）把
   这些巨大样本"求和"回真值——这是对角方案在放大区仍然精确的机制，
   也是它对非理想谱成分（插值残差/外延内容）敏感的同一枚硬币。
2. **任何带限往返都摧毁该相消**：谱域分析 `F̂ = YᵀW·F` 只保留 ≤ L 内容；
   `M·F̂` 是"精确 Gaunt 配对"——数学上等于 `⟨T_{≤L}·F, Ȳ_a⟩`，但其
   数值被 (L,2L] 乘积内容的配对主导（实测 (T⊙F) 综合投影损失 0.56 rel；
   "精确"低阶谱系数比真值大 ~10³×）。`Mc` 模式（直接用 `YᵀW·Diag(T)·Y`
   复制对角算子）同样失败——综合投影 `Y·YᵀW` 把原始乘积样本投影回 ≤ L，
   相消所需的原始样本信息不可恢复。
3. **放大区是叶层常态**：MLFMA 叶盒 kw ~ 1.6–3.1 ≪ L（L≈12–24），即
   实际运行的对角方案**始终**在依赖混叠相消的区间工作；验证"谱域 ≡ 对角"
   需要 kR ≳ 2L，任何实际 fixture 都达不到（细 fixture nr=7 叶层 kR=5.03
   仍在放大区：谱域 0.116 vs 对角 1.4e-4）。

### 6.3 结论与推论

1. **谱域（多极子域）M2L 在同网格上不能复现对角方案**，更不能在放大区
   替代它——阶段 2 原型的理想化设定（带限 F、合成即求积、无真实内容）
   恰好绕开了混叠相消机制，结论不可迁移。方案已回退，代码不留
   opt-in（错误结果比没有更糟）。
2. **对角方案的短距失效是两重性的**：(a) 几何分离不足（支撑外延 >
   R_min，GD2V 型）——任何方案都不可恢复；(b) kR_min/L 过低时混叠相消
   鲁棒性下降——正解是**增大 near_range / 电大叶盒**（自适应判据已交付），
   而非替换平移方案。
3. 若未来仍要短距 nr=1：可行方向是**加密综合网格**（容量 ≥ 3L 的专用
   接收网格，保留乘积的 (L,2L] 内容）或宽带平移（收敛核 L' > L）——
   前者等于逐点方案的重参数化（无收益预期），后者受分离判据 (a) 硬约束。
   都超出本 issue 的性价比范围。
